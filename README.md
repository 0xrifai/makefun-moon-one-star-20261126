A one-star review of the Moon, written the way a fed-up customer would write it.

## The review

> One star. Works nights only, shows up half-finished, and still expects a holiday named after it.

## How it works

`main.ts` writes the review to `/output/entry.txt` — a single line, 120 characters at most, no trailing newline. Run it with:

```sh
node main.ts
```

## Why this angle

The Moon has been coasting on reputation for billions of years. It only
clocks in after dark, it turns up to work visibly unfinished half the time,
and somehow entire holidays are still named after it. That is not a
celestial body earning five stars. That is a part-timer with great PR.

The joke lands on the Moon itself, not on a trip to it and not on some
other thing the reviewer bought. The grievance is specific: the night
shift, the half-finished phases, the holiday named in its honour. Swap
the Moon out for any other product and the line stops making sense —
which is exactly the point of a review like this.
